# checkmarx-se-demo
Application Security Demo using Checkmarx GitHub Actions

This repository has been created as part of the Checkmarx Solution Engineer technical exercise.

## Repository Structure

- nodegoat/ – Intentionally vulnerable Node.js application
- terraform/ – Infrastructure-as-Code examples
- kubernetes/ – Kubernetes manifests
- docker/ – Container configuration
- secrets/ – Sample secrets for detection

## Security Controls Demonstrated

- Infrastructure as Code Security (KICS)
- Secret Detection (Too Many Secrets)
- Static Code Analysis (Vorpal / Checkmarx)

The purpose of this repository is to demonstrate how security can be integrated into developer workflows through GitHub Actions.
